# ADA-AutoFix-Test-GitHub-3

Test site for ADA Auto-Fix, served by GitHub Pages from `docs/`:
https://vinothrajm0407.github.io/ADA-AutoFix-Test-GitHub-3/

It has exactly six known accessibility violations, each with a built-in Auto-Fix:

| # | Rule | What's wrong |
|---|------|--------------|
| 1 | `image-alt` | `<img>` has no `alt` |
| 2 | `button-name` | icon-only `<button>` has no name |
| 3 | `label` | email `<input>` has no label |
| 4 | `list` | `<div>` directly inside `<ul>` |
| 5 | `definition-list` | `<p>` directly inside `<dl>` |
| 6 | `object-alt` | `<object>` has no name |
